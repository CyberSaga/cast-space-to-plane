# 透視陰影作圖系統 — 規格增補 v0.3：場景編輯（拖曳物件、物件庫、刪除）

狀態：草案，行為已由互動 demo 驗證（§12），待確認的假設見 §11。日期：2026-10-09。
放置位置：`docs/spec/spec-v0.3.md`（與 `spec-v0.1.md`、`spec-v0.2.md` 並列）。行為參考：`docs/demo/scene_edit_demo.html`。

## 0. 與 v0.1、v0.2 的關係

本文件是增補，不取代 v0.1 與 v0.2。新增三件事：在 3D 空間中拖曳物件；從預設折疊的側邊欄「物件庫」點一下加入預設物件；選取物件後按 Delete 刪除。里程碑為 M11，接在 v0.2 的 M10 之後。

**核心不變**：這些都是網頁對場景 JSON 的編輯，核心（A、B、C 段）與一致性測試集都不需要改。物件仍使用 v0.1 §4 的型別、欄位與錨點慣例（底面中心，放在地面時 z = 0）。

本文件修訂 v0.2 的五處（v0.2 原文不改，以本節為準）：

| v0.2 位置 | 原規則 | 修訂後 |
| --- | --- | --- |
| §4.2、§5.4 旋轉中心 | 「場景中心」即時取 A 段包圍盒中心；「點選物體」在左窗點一下設定 | 旋轉中心是**設定當下取值的點**，之後新增、拖曳、刪除物件都不移動它（§4.3）；「點選物體」改由選取決定（§3） |
| §3 頂點射線的焦點物體 | 場景第一個物體 | 有選取時為選取的物件，否則為第一個物件 |
| §5.7 復原 | 只有板子與相機操作 | 加入物件的新增、拖曳、刪除，另加重做（§7） |
| §5.7 重設 | 回到初始狀態 | 只重設視角（板子、旋轉中心、旁觀相機），不還原物件；按鈕改名「重設視角」 |
| §3 旁觀相機取景 | 取景點含場景中心與其地面點 | 改為場景包圍盒的八個角，新加的物件才不會落在畫面外 |

### 0.1 名詞

| 名詞 | 定義 |
| --- | --- |
| 物件 | 場景 `objects` 裡的一個基元（`box`、`cylinder`、`sphere`、`cone`、`prism`）。光源與受影面不算物件，不能用本文件的操作編輯 |
| 錨點 | 物件 `transform.position`，即底面中心 |
| 底面高度 | 錨點的 z，記為 z_b，限制 z_b ≥ 0 |
| 選取 | 目前被選中的物件，最多一個 |
| 物件庫 | 預設折疊的側邊欄，列出預設物件的圖塊 |
| 圖塊 | 物件庫裡的一格：縮圖加一行名稱，點一下即加入物件 |

## 1. 範圍與已定案決策

| 決策 | 內容 |
| --- | --- |
| 拖曳 | 在左窗（旁觀視角）與右窗（作圖畫面）都能拖曳物件；預設沿水平面移動，另有垂直把手調整高度 |
| 物件庫 | 側邊欄預設折疊；展開後以圖塊（縮圖加一行名稱）呈現；點一下即把該物件加入 3D 空間 |
| 刪除 | 點選物件後按 Delete（或 Backspace）刪除；觸控裝置用選取後出現的刪除鈕 |
| 核心 | 不變；網頁編輯場景 JSON 後照常重算 A、B、C 段 |

不在本次範圍：旋轉與縮放物件、數值檢查面板、從物件庫拖放到畫面、編輯光源與受影面、從物件庫匯入網格、物件之間的碰撞或吸附。

| 區域 | 內容 |

| 選取標示 | 兩窗都以強調色描出選取物件的外框，左窗另外顯示垂直把手與名稱標籤；這些是介面疊加層，不進輸出 |

行為：

- 每次載入時物件庫都是折疊的。
- 展開與收合：點分頁鈕、標題列的收合鈕，或按 Esc。窄螢幕（寬度 < 880 px）時，側邊欄寬度改為 min(80%, 280 px)，點側邊欄以外的地方也會收合。
- 窄螢幕點圖塊加入物件後，側邊欄自動收合，讓使用者看到結果；寬螢幕保持展開，可連續加入。
- 縮圖是內嵌 SVG 線稿，使用 `currentColor`，隨淺色與深色主題變色；每種預設物件一張，以同一個斜視角度繪製。
- 圖塊可用鍵盤操作：Tab 移動焦點，Enter 或空白鍵加入。每個圖塊的 `aria-label` 為「加入：名稱」。

## 3. 選取

| 動作 | 結果 |
| --- | --- |
| 在物件上點一下（位移 < 5 px） | 選取該物件 |
| 在物件上按住拖曳（位移 ≥ 5 px） | 選取並開始拖曳該物件（§4） |
| 在空白處點一下 | 清除選取 |
| Esc | 物件庫展開時先收合物件庫；否則清除選取 |
| 新增物件 | 新物件成為選取 |
| 刪除物件 | 清除選取 |

命中測試：視線最先射中的物件，也就是多個物件重疊時取最近者。

點擊優先序：

- 左窗：箭頭尖端 > 圓環 > 選取物件的垂直把手 > 物件 > 空白處（拖曳＝轉動旁觀視角）。
- 右窗：物件 > 空白處，空白處的拖曳照 v0.2 §5.9（左拖環繞、右拖或 Shift 拖平移、滾輪距離）。在物件上按下時，左拖改為拖曳物件；要環繞時從空白處開始拖。

與旋轉中心的關係：旋轉中心為「點選物體」模式時，**點一下**選取物件，就把旋轉中心設為它當下的包圍盒中心（§4.3）；在物件上直接拖曳只選取、不改旋轉中心，免得一開始拖曳畫面就跳動。尚未選取時暫用場景中心。

- 圓環畫過物件的地方，以圓環優先（命中寬度約 11 px）；要拖那個物件，從物件的其他部位按下。
- 觸控雙指：第一根手指落在物件上、移動不到 5 px 時第二根手指就到來，視為雙指手勢（捏合＝板子距離、一起移動＝平移）：取消物件拖曳、物件回到原位、選取還原，整個手勢只記一步復原。物件已移動 5 px 以上時，忽略第二根手指。

## 4. 拖曳物件（規範性）

### 4.1 沿水平面移動

拖曳物件本體時，物件沿水平面移動，z_b 不變。按下時取抓到的表面點 h₀，它的高度為 z_g；水平面為 z = z_g。把錨點與 h₀ 的水平差記為抓取偏移 o，使抓到的點一直留在手指下：

```latex
t = \frac{z_g - o_z}{d_z},\qquad h = o + t\,d,\qquad (x_b, y_b) = (h_x, h_y) + (o_x, o_y)
```

其中 o、d 為指標射線的起點與單位方向（左窗用旁觀相機，右窗用作圖相機），o_x、o_y 為抓取偏移的分量。

- **擦掠角後備**：按下時若 |d_z| < sin 5° 或 t ≤ 0，射線與水平面的交點不可靠，整次拖曳改用螢幕位移（按下時判定，拖曳中不切換，避免跳動）；正常模式下若某次 |h − o| > 200 m，該次不更新。每像素公尺數為 `k = 物件深度 / 每像素焦距`。右拖量沿相機右向量投影到地面的方向，下拖量沿相機前方向投影到地面的反方向。
- 預設視角（眼高 0.9 m、水平看出去）下，右窗多數點擊的俯角小於 5°，會走後備：左右拖跟著手指，上下拖把物件推遠或拉近。俯視角度越大越接近「抓點留在指標下」。
- **範圍**：|x_b|、|y_b| ≤ 50 m。
- **吸附**：沿用 v0.2 的「吸附」勾選框與 Alt 暫停；開啟時 x_b、y_b 各貼到 0.1 m 格點。關閉時位置四捨五入到 1e-4 m，讓儲存的場景檔數字簡潔。

### 4.2 垂直把手

選取的物件在左窗顯示一個垂直把手：從物件頂端中心往上的箭頭，長度取 clamp(0.6 × 物件高度, 0.3, 1.0) m，且在螢幕上至少 36 px（遠處物件的把手太短時，尖端會貼著物件頂面、搶走拖曳物件的點擊）。拖曳把手時，物件只沿 z 移動：

- 取指標射線與「按下時錨點」所在垂直線最近點的參數 s（兩直線最近點公式）；`z_b = clamp(z_b0 + (s − s₀), 0, 50)`。
- 吸附開啟時 z_b 貼到 0.1 m 格點；關閉時四捨五入到 1e-4 m，且小於 0.02 m 時貼回地面，所以地面 z_b = 0 永遠是吸附點。
- 右窗不顯示垂直把手：在作圖畫面裡判斷高度不直覺，垂直移動只在左窗做。

### 4.3 旋轉中心不跟著物件移動（修訂 v0.2）

v0.2 的眼睛位置 `E = P − (g + D) f + L` 依賴旋轉中心 P。若 P 隨物件即時改變，拖曳或刪除物件會讓畫面跟著跳動，所以：

- P 是**設定當下取值的點**。「場景中心」在載入場景、重設、切換到「場景中心」模式，以及按「重新取中心」時，取當下 A 段包圍盒中心；「點選物體」在選取時取該物件當下的包圍盒中心。
- 之後新增、拖曳、刪除物件都不移動 P，包括拖曳的正是作為旋轉中心的那個物件。
- 新增「重新取中心」按鈕，放在旋轉中心選擇旁：依目前模式重新取值。眼睛會跳到新的軸線上，這一步不進復原堆疊（同 v0.2 更換旋轉中心的規則）。

### 4.4 重算與效能

- 物件改變時重算 A、B、C 段；每個動畫格最多重算一次。
- 目標：10 個基元以內的場景，拖曳時每次更新 < 33 ms。
- 若上一次完整重算超過 50 ms，拖曳期間改為預覽：只畫物件線框，不畫陰影與作圖線；放開時才完整重算。
- 拖曳期間右窗的「畫面變動」讀數（v0.2 §5.8）照常更新。

## 5. 物件庫

### 5.1 預設物件

| 圖塊名稱 | type | 參數 | id 字首 |
| --- | --- | --- | --- |
| 方塊 | `box` | `size` [1, 1, 1] | `box` |
| 木箱 | `box` | `size` [1.2, 0.9, 0.7] | `box` |
| 高柱 | `box` | `size` [0.6, 0.6, 1.8] | `box` |
| 圓柱 | `cylinder` | `radius` 0.3、`height` 1.2 | `cylinder` |
| 球 | `sphere` | `radius` 0.5 | `sphere` |
| 圓錐 | `cone` | `radius` 0.4、`height` 1.0 | `cone` |
| 三角柱 | `prism` | 邊長 1.0 的正三角形（形心在原點、逆時針）、`height` 1.0 | `prism` |
| 六角柱 | `prism` | 外接圓半徑 0.4 的正六邊形（逆時針）、`height` 1.0 | `prism` |

新物件的 `transform.rotation_deg` 為 [0, 0, 0]，z_b = 0。預設物件清單寫成一個資料表（名稱、型別、參數、縮圖），新增一種只需加一列。

### 5.2 放置位置

點圖塊後，依序決定落點：

1. 目標點 T：作圖相機的視線（E + t·f）與地面 z = 0 的交點，條件是 f_z < −sin 2° 且交點離眼睛 ≤ 40 m；否則取旋轉中心正下方的地面點 (P_x, P_y, 0)。
2. 避讓：若新物件的水平包圍矩形與既有物件（以其世界座標包圍盒計）重疊，間距不足 0.1 m，就沿相機右向量投影到地面的方向，每次移動「新物件寬度 + 0.2 m」，最多 8 次；仍重疊就放在最後的位置。
3. 吸附開啟時貼到 0.1 m 格點。

### 5.3 id

新物件 id 為 `字首_n`，n 取 ≥ 1 中最小的、不與任何物件、光源、受影面 id 重複者。id 不含 `.`，也不等於保留字 `hidden`（contract §2.0）。顯示名稱用圖塊名稱，不寫進場景 JSON。

## 6. 刪除

- 有選取時按 Delete 或 Backspace 即刪除。若焦點在文字類輸入欄位（text、search、number 等，例如平面方程式欄位）或可編輯區域，不攔截這兩個鍵；焦點在滑桿、勾選框、按鈕時照常刪除。
- 觸控或滑鼠：按選取晶片上的刪除鈕。
- **至少保留一個物件**：核心要求 `objects` 不可為空（contract §2.0）。只剩一個物件時刪除鈕停用並顯示提示「場景至少要有一個物件」，按 Delete 也只顯示提示。
- 刪除後清除選取；旋轉中心不受影響（§4.3）。

## 7. 復原與快捷鍵

- 與 v0.2 共用同一個復原堆疊，最多 50 步。新增一個物件、刪除一個物件、一次拖曳（放開時結算，沒有實際移動則不記）各算一步。選取的改變與物件庫的展開收合不記。
- 復原刪除時，物件以原 id、原參數放回 `objects` 的**原索引**，所以輸出與刪除前逐位元相同。
- 工具列有「復原」與「重做」；任何新動作都會清空重做堆疊。
- 快捷鍵：Ctrl+Z（macOS 為 ⌘Z）復原，Ctrl+Shift+Z（⌘⇧Z）重做；焦點規則同 §6。
- 「重設視角」只重設板子、旋轉中心與旁觀相機，不還原物件；它本身記一步復原，所以誤按可以復原。

## 8. 輸出與儲存

- 新物件附加在 `objects` 末端；刪除保留其他物件的相對順序。
- 「Download scene」輸出編輯後的場景，可直接用 Python 命令列重現同一張圖。
- 幾何文件與 SVG 照常由核心產生；選取外框、垂直把手、選取晶片都是介面疊加層，不進輸出。

新增一個「木箱」後，場景 JSON 多出的物件：

```json
{"id": "box_1", "type": "box", "size": [1.2, 0.9, 0.7],
 "transform": {"position": [0.4, 3.1, 0.0], "rotation_deg": [0.0, 0.0, 0.0]}}
```

## 9. 退化情況

| 情況 | 處理 |
| --- | --- |
| 視線幾乎平行地面時拖曳 | 擦掠角後備（§4.1） |
| 物件拖到相機背後或畫框外 | 照算；照既有近平面裁切 |
| 物件頂端高過點光源，或光源落在物件內 | 照算；核心照既有規則發出警告（例如影子無界），顯示在讀數區 |
| 拖出 ±50 m 或 z_b 超出 [0, 50] m | 夾限 |
| 只剩一個物件時刪除 | 不刪，顯示提示 |
| 新 id 衝突 | 依 §5.3 取下一個可用的 n |
| 焦點在文字欄位時按 Delete、Backspace、Ctrl+Z | 交給文字欄位，不刪物件、不復原 |
| 拖曳中重算超過 50 ms | 拖曳期間改為線框預覽，放開才完整重算（§4.4） |
| 圓環畫過物件 | 該處以圓環優先；從物件其他部位按下即可拖曳物件 |
| 雙指手勢的第一根手指落在物件上 | 物件移動不到 5 px 時改為雙指手勢，物件回原位（§3） |

## 11. 本文件替你做的選擇，請確認

- 垂直移動只在左窗用把手做，右窗只能水平拖曳。
- 右窗在物件上按下時，左拖改為拖曳物件；要環繞時從空白處開始拖。
- 旋轉中心是設定當下取值的點，物件編輯不移動它，另加「重新取中心」按鈕（修訂 v0.2）。
- 至少保留一個物件（因為核心要求），而不是修改核心去允許空場景。
- 八個預設物件與它們的尺寸；新物件旋轉為 0、放在地面。
- 物件庫覆蓋在畫面之上而不推擠畫布；窄螢幕加入物件後自動收合。
- Backspace 也能刪除（macOS 鍵盤的 delete 鍵就是 Backspace）；另加 Ctrl+Z／⌘Z 復原快捷鍵。
- 「點選物體」模式下，點一下才設定旋轉中心，拖曳物件不改。
- 「重設視角」不還原物件。
- 垂直把手從物件頂端往上，螢幕上至少 36 px。
- 擦掠角後備在按下時判定，整次拖曳不切換。
- 候選但未納入：L 形牆（凹多邊形柱體）。核心已支援：合約 §2.0 對 `prism.polygon` 只要求簡單多邊形（順時針輸入會被靜默反轉），陰影用 `nonzero` 填色規則，測試也含凹柱體。限制在 demo 與編輯介面：demo 的影子以頂點凸包計算、命中測試也只驗證過凸體。正式實作用核心輸出，不受此限，可在 M11 之後把凹柱體加進物件庫。

## 12. 行為參考：互動 demo

`scene_edit_demo.html` 是單檔互動 demo，包含 v0.2 的全部操作與本文件的場景編輯，驗證過上述規則，可作為手感與行為的參考實作。它不是規範：兩者不一致時以本文件為準。與核心實作的差異：

- 圓柱、圓錐、球以多邊形近似（圓周 24 段；球為 16 × 8），只畫輪廓邊與夾角大於 25° 的稜邊；核心用精確的圓錐曲線。
- 物件高過光源時，demo 直接不畫它的影子並提示；核心則照既有規則處理並發出警告。
- 影子以「頂點投影後取凸包」計算，只適用凸體；核心沒有這個限制（凹柱體的輪廓可能是多個迴圈）。
- 沒有場景檔的載入與儲存；場景（三個方塊、一盞點光）是自訂的。
