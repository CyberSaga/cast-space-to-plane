# tools/charmodel: the shared character-model toolkit

`charmodel` is the character-free half of the castplane character generators (`tools/<name>_model/`, run by
`tools/make_<name>_model.py`). It holds the mesh builders, the assembly of parts into castplane objects, the scene /
OBJ / MTL / GLB writers, the previews, the overlay check against the design sheet and the command line. A character
package holds everything that is about one character: its rig, its part builders, its mannequin, its objects, its
materials, its texts, its camera presets and, if it has a design sheet to check against, the data of its overlay.
Nothing in `charmodel` names a character, and no character number, colour or text lives here: every such value comes in
through a parameter. `tools/miki_model/` and `tools/reiya_model/` are the two worked examples. Miki's `README.md` is
the maintainer guide (the part / object / material model, the 10 mesh rules, the CLI options); Reiya's covers what a
second character adds (the stated-height `scale`, per-side objects, the fan rule). The process is in
`.claude/skills/character-model/SKILL.md`.

The generators run with `tools/` on `sys.path` (the `make_*_model.py` scripts and the tests put it there), so a
character package imports this one as the top-level package `charmodel`.

## Modules

| module | what it holds | imports |
| --- | --- | --- |
| `meshkit.py` | `Mesh`, `Part`, `MeshError`, the closed-shell builders (`loft`, `sweep`, `tube`, `thicken`, `revolve`, `ellipsoid`, `superellipsoid`, `torus`, `strip_plate`, `ridge_band`), ring / profile / polyline helpers, `validate`, `fix_nesting`, `split_smooth`, `feature_silhouette_vertices`, the fan-diagonal helpers (`inscribed_fan`, `fan_fold`, `split_twisted`, `_below_fan` with `PLANAR_REL`) and the decal-clearance helpers | numpy, stdlib |
| `assembly.py` | `Character` (the character description, with an optional uniform `scale`), `Assembly`, `AssemblyError`, `build_parts`, `scale_parts`, `assemble`, `compute_stats`, `format_stats` | numpy, stdlib |
| `export.py` | `scene_dict` / `scene_text` / `write_scene`, `check_scene`, `mtl_text`, `obj_text`, `write_obj`, `glb_bytes`, `write_glb`, `srgb`, `srgb_to_linear`, `sun_direction` | numpy, stdlib; castplane lazily (`check_scene`) |
| `preview.py` | `Cameras` (presets + framing), `render_shaded` (numpy z-buffer; back faces magenta), `with_context`, `shaded_views`, `write_shaded_previews`, `contact_sheet`, `side_by_side`, `castplane_views`, `write_line_previews` | numpy, stdlib; Pillow, cairosvg and castplane lazily |
| `overlay.py` | the overlay check against a design sheet and the mesh smoothness metrics: the data a character supplies (`SheetView`, `SheetSpec`, `Outline`, `LowerEdge`, `Landmark`, `Probe`, `Criterion`, `OverlaySpec`), `render_view` (the orthographic numpy z-buffer), `load_sheet` / `read_sheet`, `compare_view`, `dihedral_stats`, `outline_turns`, `front_view`, `mesh_distance`, `shaded_probe`, `evaluate_criteria`, `run_overlay`, `write_report` | numpy, stdlib, `meshkit`; Pillow lazily |
| `cli.py` | `Tool` (what the CLI needs from a package, including the optional `overlay` data), `main(tool, argv)`, `castplane_check` | stdlib; castplane lazily |

The geometry modules keep the numerical rules of the Miki generator (rule 9 of `tools/miki_model/README.md`): no
randomness, no set iteration order, coordinates rounded to `Character.decimals`, relative tolerances where the last bit
of a float reduction could decide a branch. Do not reorder their arithmetic: the generated bytes of every character
depend on it, and `tests/test_<name>_model.py` pins them.

## API

`charmodel.assembly`:
- `Character(name, objects, materials, display_materials, region_objects, modules, mannequin, rig_factory,
  sun_towards, budget, decimals=5, scale=None)`: the description (the constructor checks that the pieces agree and
  raises `AssemblyError`); `.object_ids`, `.all_regions`, `.display_color(oid)`, `.scale_for(rig)`.
- `build_parts(character, rig, only=None) -> (parts, sources)`: the parts of every region (or of `only`: regions or
  module names), with `obj` resolved; a module whose `build(rig)` returns `None` is replaced by the mannequin; with a
  `scale`, every part is scaled by it (`scale_parts(parts, factor)`).
- `assemble(character, rig=None, only=None, strict=True) -> Assembly`: round, validate, merge per object (smooth groups
  renumbered per part, face ranges and materials kept), `fix_nesting`, validate the objects, statistics.
- `Assembly(rig, parts, sources, meshes, part_faces, reports, stats)`: `.ok`, `.materials(oid)`, `.objects()` (the
  castplane mesh object dicts).
- `compute_stats(character, assembly) -> dict`; `format_stats(stats, object_ids, parts=True) -> str`.

`charmodel.export`:
- `scene_dict(character, assembly, settings, description)`, `scene_text(...)`, `write_scene(character, assembly, path,
  settings, description)`: the scene of `settings` (keys `version`, `units`, `up`, `lights`, `receivers`, `camera`,
  `output`; the first light's `direction` becomes the normalised `character.sun_towards`) with one inline mesh object
  per castplane object and its `display_color`.
- `check_scene(text)`: the castplane load plus a re-validation of the written coordinates.
- `mtl_text(character, header)`, `obj_text(assembly, mtl_name, header)`, `write_obj(character, assembly, obj_path,
  mtl_path, obj_header, mtl_header)`: the header lines are written as given (put the copyright notice in them).
- `glb_bytes(character, assembly, generator, copyright)`, `write_glb(character, assembly, path, generator, copyright)`:
  the glTF scene is named `character.name`.

`charmodel.preview`:
- `Cameras(presets, height, upper_bottom_z, head_target, head_fit, frame_mm=(24, 36), ...)`: `presets` is `{name:
  (azimuth deg, elevation deg, framing, focal mm)}` with the framings `"body"`, `"upper"` and `"head"`;
  `.camera(preset, bbox=None)` gives the castplane camera dict.
- `render_shaded(model, camera, *, materials, light, size, supersample, ground, lines)` returns a Pillow image;
  `shaded_views(model, cameras, presets, *, materials, light, size)`; `write_shaded_previews(model, out_dir, cameras,
  body, head, *, materials, light, ...)`; `with_context(model, rig, *, materials, mannequin)`.
- `castplane_views(scene, cameras, presets, hidden, px, jobs, layers)` and `write_line_previews(scene, out_dir,
  cameras, presets, ...)`: the real castplane line drawing per preset.

`charmodel.overlay` (see "The overlay check" below):
- `OverlaySpec(sheet, figure_scale, material_classes, bands, ...)`: everything a character says about its sheet,
  built from `SheetSpec` / `SheetView` (the mappings, the colour classes, the paper's `background_greys` and
  `label_greys`, which have no defaults), `Outline`, `LowerEdge`, `Landmark`, `Probe`
  and `Criterion(id, text, keys, op, limit, note)`; the pass condition reduces the report values at `keys` (dotted
  paths, `*` matches a level) with `op` (`<=`, `>=`, `abs<=` or `between`). A key without a `*` that has no value (a
  landmark not found, a part not seen) makes the criterion n/a, neither a pass nor a failure; the record lists the
  `missing` keys.
- `run_overlay(model, rig, spec, sheet_path, out_dir, views=None, smooth=True, repo=None, title=...) -> dict` runs the
  whole check and writes `report.json`, `report.md` and the images; `evaluate_criteria(report, criteria)`;
  `dihedral_stats(mesh, ...)` and `outline_turns(mesh, camera, ...)` are the smoothness metrics on their own
  (`outline_turns` merges outline edges that coincide within `merge_px` pixels, such as the two rims of shells that meet
  at a cut, and counts turns over `fold_deg` as folds, not tips).

`charmodel.cli`:
- `Tool(name, title, rig, assemble, export, preview, repo, description="", max_scene_kib=700, overlay=None)` and
  `main(tool, argv=None) -> int`: the options and exit statuses of `make_miki_model.py` (0 ok; 1 invalid, over budget,
  over the scene size, castplane warnings or a failing overlay criterion; 2 usage error), plus `--overlay SHEET DIR`
  when `Tool.overlay` is a module with `SPEC` (a character without one gets exit status 2).

## Designing at the sheet scale, scaling to a stated height

Measure and build a character at the scale of its design sheet (one scale for every view), and give `Character` a
`scale` when the character's real height is known: a number, or a function of the rig such as
`lambda rig: rig.stated_height / rig.skin_height`, so a `--rig` override of the height rescales the model.
`build_parts` multiplies every part's vertices (the mannequin's too) by it about the origin, elementwise and before the
rounding, so the soles stay on `z = 0`, the bytes stay deterministic and the rig, the spec and the builders keep the
sheet's numbers. The character's writers scale the scene camera's position and target by the same factor (the picture
stays the same) and its previews scale their framing heights. A relief, float or gap shrinks with the model: re-check
rule 5 (decals >= 0.5 mm proud) on the scaled model. The default `scale=None` leaves the code path and the bytes of a
character without it unchanged (Miki). `tools/reiya_model/` is the example (`assemble.figure_scale`,
`export.scene_settings`, `preview.cameras`).

## The overlay check (`overlay.py`)

`make_<name>_model.py --overlay SHEET.png DIR` lays the model over its design sheet and measures the differences, the
check mesh-avatar-studio runs with a very long lens. The sheet's views are near-orthographic, so the model is rendered
**orthographically** (the limit of a very long lens, with no lens scaling error) by a numpy z-buffer straight into the
sheet's pixel grid: `u = origin_px + (P . h_axis) / s`, `v = ground_row - P_z / s`, one scale `s` (metres per pixel)
for every view. The model is built at the sheet's scale and then scaled to the stated height (`Character.scale`), so
the check divides it by that factor first, and it quotes every offset in **mm on the final model** (sheet pixels x `s`
x the figure scale; Reiya: 0.601 mm per pixel). The sheet is read the same way on both images: a flood fill of its
light grid from the border of the view's box gives the silhouette, a nearest-colour classification gives the class
regions (hair, skin, white garments, ...), and the ink line takes its neighbours' class. Per view, `DIR` gets
`overlay_<view>.png` (the sheet at 50 %, the class-coloured model at 50 % over it, the model's outlines green and the
sheet's magenta) with zoomed crops, `diff_<view>.png` (red: sheet only, blue: model only, orange: different classes),
and `report.md` + `report.json` hold every number: the silhouette per row band (left / right offsets, the half-width
error that cancels a sideways shift of the drawing), per-class IoU, class outlines per row, lower edges per column,
named landmarks, plus mesh **smoothness** (the dihedral angles inside one smooth group, and the turning angles of a
part's 2D outline in perspective review views, tips, folds and group boundaries excluded; both count only what the whole
model shows from the review cameras, by a z-buffer of every part), shaded colour probes and the
character's extras (pose, clearances), each criterion with its pass / fail / n/a. A failing criterion makes the exit
status 1 (n/a does not); the command prints `N of M pass; n/a: ids; failing: ids`, N counting passes only, as
`report.md` does; a character without overlay data (`Tool.overlay` is `None`, e.g. Miki) gets exit status 2.

The character supplies everything about its sheet in `tools/<name>_model/overlay.py` as `SPEC`, a
`charmodel.overlay.OverlaySpec`: the view mappings and boxes, the class colours and the material -> class map, the
row bands, outlines, lower edges, landmarks, zooms, smoothness parts and views, and the pass criteria
(`tools/reiya_model/overlay.py` is the example). **The design sheet never enters the repository**: pass its path from
outside, and keep `DIR` outside too (the overlay images contain the sheet; the CLI refuses a `DIR` inside the
repository). `tests/test_charmodel_overlay.py` checks the method on a synthetic sheet made from the model's own
render.

## What a character package provides

The file list of the skill: `tools/<name>_model/` with `__init__.py`, `README.md`, `SPEC.md`, `rig.py`, `mannequin.py`,
the part modules, `assemble.py`, `export.py`, `preview.py` and, optionally, `overlay.py`; `tools/make_<name>_model.py`;
`tests/test_<name>_model.py`.
The thin layers (`assemble.py`, `export.py`, `preview.py`, `make_<name>_model.py`) are best copied from
`tools/miki_model/` and `tools/make_miki_model.py` (or from `tools/reiya_model/` and `tools/make_reiya_model.py`, which
also pass `scale=`), keeping the wrapper functions and replacing the data. The names
the toolkit, the CLI and the tests rely on:

| file | must define |
| --- | --- |
| `rig.py` | `Rig` (a frozen dataclass: `Rig()` is the default rig, `Rig.from_dict(dict)` applies `--rig`) and `SUN_TOWARDS` |
| part modules (`head.py`, ...) | `REGIONS` (tuple of region names) and `build(rig) -> list[Part] or None`; parts are `charmodel.meshkit.Part` |
| `mannequin.py` | `REGIONS` (every region of the part modules) and `build(rig, regions=None) -> list[Part]` |
| `assemble.py` | the data `OBJECTS`, `MATERIALS`, `DISPLAY_MATERIALS`, `REGION_OBJECTS`, `MODULES`, `BUDGET`, `DECIMALS`; `CHARACTER = Character(...)`; `OBJECT_IDS`, `ALL_REGIONS`, `display_color(oid)`, `build_parts(rig, only=None)`, `assemble(rig=None, only=None, strict=True)`, `format_stats(stats, parts=True)`, and the re-exported `Assembly`, `AssemblyError` |
| `export.py` | the texts `SCENE_SETTINGS`, `DESCRIPTION`, `OBJ_HEADER`, `MTL_HEADER`, `GLB_GENERATOR`, `GLB_COPYRIGHT` (with the copyright notice); `scene_dict(model)`, `scene_text(model)`, `write_scene(model, path)`, `check_scene(text)`, `mtl_text(model)`, `obj_text(model, mtl_name)`, `write_obj(model, obj_path, mtl_path)`, `glb_bytes(model)`, `write_glb(model, path)` |
| `preview.py` | `PRESETS`, `BODY_PRESETS`, `HEAD_PRESETS`, `FRAME_MM`; `cameras(rig=None) -> Cameras` (the framing numbers from the rig); `camera_for(preset, rig=None, bbox=None)`, `render_shaded`, `with_context(model, rig=None)`, `shaded_views`, `write_shaded_previews(model, out_dir, rig=None)`, `castplane_views`, `write_line_previews(scene, out_dir, presets, rig=None, hidden=True, layers=None)` |
| `overlay.py` (optional) | `SPEC`, a `charmodel.overlay.OverlaySpec`; the script passes the module as `overlay=` of the `Tool` (`tools/reiya_model/overlay.py`) |
| `make_<name>_model.py` | puts `tools/` on `sys.path`, builds `TOOL = cli.Tool(name=..., title=..., rig=Rig, assemble=assemble, export=export, preview=preview, repo=REPO)` and calls `cli.main(TOOL, argv)` |

A minimal `make_<name>_model.py`:

```python
#!/usr/bin/env python3
"""Build the <Full Name> drawing-reference model and write it for castplane (dev tool)."""

from __future__ import annotations

import os
import sys

HERE = os.path.dirname(os.path.abspath(__file__))
REPO = os.path.dirname(HERE)
sys.path.insert(0, HERE)

from charmodel import cli  # noqa: E402
from name_model import assemble, export, preview  # noqa: E402
from name_model.rig import Rig  # noqa: E402

TOOL = cli.Tool(name="name", title="<Full Name>", rig=Rig, assemble=assemble, export=export, preview=preview, repo=REPO)


def main(argv=None) -> int:
    return cli.main(TOOL, argv)


if __name__ == "__main__":
    sys.exit(main())
```

A change to this package changes every character's output it touches: regenerate each one (`make_<name>_model.py
--check`) and run each `tests/test_<name>_model.py`; a refactor must leave all their files byte for byte identical.
